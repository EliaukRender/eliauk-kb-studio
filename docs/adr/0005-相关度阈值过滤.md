# 0005 相关度阈值过滤

- 状态：已采纳
- 日期：2026-10-20
- 涉及模块：`rag`

## 背景

向量检索总会返回 top_k 条最相似的结果，即使它们和问题无关。无关片段会诱导模型强行作答，或者乱标来源。

## 决策

- 检索时取 top_k（默认 4），丢弃余弦相关度低于 `score_threshold`（默认 0.4）的片段。
- 默认值来自实测：无关问题的最高相关度不超过 0.32，相关问题的最佳匹配不低于 0.56（`text-embedding-v4`）。
- Prompt 兜底：资料中没有答案时回答“没有找到”，不标注来源。
- 不使用 `similarity_score_threshold` 检索器，因为结果为空时它会输出 UserWarning。直接调用 `similarity_search_with_relevance_scores` 自行过滤。

## 备选方案

- 只靠 Prompt 约束：模型仍会受无关片段干扰，来源标注也不可靠。
- Rerank 精排：效果更好，但要接入额外的模型服务，列为后续扩展。

## 影响

- 阈值和 Embedding 模型绑定，换模型后必须重新校准，通过回归测试验证。
- 有共同词的无关问题（如“公司有健身房吗”）仍可能高于阈值，需要依赖 Prompt 兜底。
