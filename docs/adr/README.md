# 架构决策记录（ADR）

记录影响模块边界、数据结构、对外接口或技术选型的决策，以及做出决策时的背景和取舍。

## 规则

- 文件名 `NNNN-主题.md`，编号递增，不复用。
- ADR 一经“已采纳”不再修改正文；决策变化时新建 ADR，并把旧 ADR 的状态改为“已被 NNNN 取代”。
- 状态取值：提议中、已采纳、已弃用、已被 NNNN 取代。
- 保持简短：背景、决策、备选方案、影响，各写几句即可。
