# 0006 回归测试采用关键词判定

- 状态：已采纳
- 日期：2026-10-20
- 涉及模块：`eval`

## 背景

切换索引版本前，需要一个可重复执行的质量参考，结果要稳定，并且不增加额外成本。

## 决策

- 用例分两类：普通用例要求回答包含全部期望关键词；拒答用例要求回答出现“没有找到”。
- 判定前去掉所有空白字符，避免排版差异导致误判。
- 普通用例的回答中出现“没有找到”时直接判为不通过。

## 备选方案

- LLM-as-judge：能判断语义，但结果有波动，而且每条用例要多一次模型调用，列为后续扩展。
- 与参考答案比较向量相似度：阈值难以解释，排除。

## 影响

- 判定结果可预测，适合作为“不退步”的底线检查，但无法评价回答质量的高低。
- 关键词要选择答案中的事实性片段（数字、专有名词），避免选同义表达较多的词。
