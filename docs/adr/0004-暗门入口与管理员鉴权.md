# 0004 暗门入口与管理员鉴权

- 状态：已采纳
- 日期：2026-10-20
- 涉及模块：`auth` `web-chat`

## 背景

客户端默认只展示问答，管理功能需要隐藏，同时不能让入口本身成为唯一的防线。

## 决策

- 前端提供三个隐藏入口：快捷键、连点 Logo、`/admin` 命令。未登录访问后台路由时退回问答页。
- 后端负责真正的访问控制：
  - 管理员密码用 scrypt 加随机盐存储，比对时用常量时间比较
  - 登录后签发随机 token，保存在内存中，8 小时过期
  - 所有 `/api/admin/*` 接口通过 `require_admin` 校验
- 后端只监听 `127.0.0.1`。

## 备选方案

- 只靠隐藏入口：知道路径的人就能访问，排除。
- JWT：本地单用户场景不需要无状态的 token，内存 token 更简单，也能立即注销。

## 影响

- 后端重启后需要重新登录。
- 忘记密码时，需要删除 `kv` 表中的 `admin_password_hash` 记录，或者删掉整个 `data/`。
